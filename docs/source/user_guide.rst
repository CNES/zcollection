User guide
==========

This guide covers the main operations on collections, from creating and
managing them to migrating older collections to Zarr 3.

Start with :doc:`install` and :doc:`getting_started`. The latter walks
through creating a collection, inserting and reading data, and adding a
variable.

The remaining pages explore individual topics in more detail, including
partitioning, inserting, computing on and updating data, variable and
partition management, failure handling, index maintenance, and migration.
